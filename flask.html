1.1 Sua primeira aplicação Flask

Uma aplicação Flask é apenas um arquivo Python que cria um objeto app e associa funções a URLs. Cada função é chamada de view.

# app.py
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "<h1>Olá, Flask!</h1>"

Execute com flask --app app run --debug e acesse http://127.0.0.1:5000. O modo debug recarrega automaticamente ao salvar e mostra páginas de erro legíveis.

Exercício 1.1 — Olá, você10 min

Adicione uma rota /sobre que retorne um parágrafo curto sobre você. Depois adicione uma rota /cardapio que retorne uma lista HTML com 3 das suas comidas favoritas.

Solução
@app.route("/sobre")
def sobre():
    return "<p>Estou aprendendo Flask esta semana.</p>"

@app.route("/cardapio")
def cardapio():
    return "<ul><li>Pizza</li><li>Sushi</li><li>Tacos</li></ul>"

1.2 Rotas dinâmicas

Trechos da URL podem ser capturados como variáveis e passados diretamente para a função de view.

@app.route("/ola/<nome>")
def ola(nome):
    return f"<h1>Oi, {nome}!</h1>"

@app.route("/quadrado/<int:n>")
def quadrado(n):
    return f"O quadrado de {n} é {n * n}"
Conversores de tipo como <int:n> validam a URL automaticamente — acessar /quadrado/abc retorna um erro 404 sem código extra.
Exercício 1.2 — Mini calculadora15 min

Crie uma rota /soma/<int:a>/<int:b> que retorne a soma de a e b em forma de frase, por exemplo "3 + 4 = 7".

Solução
@app.route("/soma/<int:a>/<int:b>")
def soma(a, b):
    return f"{a} + {b} = {a + b}"

1.3 Templates com Jinja2

Em vez de retornar strings puras, renderize arquivos HTML guardados numa pasta templates/. O Jinja2 permite inserir lógica parecida com Python dentro do HTML usando {{ }} e {% %}.

# app.py
from flask import Flask, render_template

@app.route("/perfil/<nome>")
def perfil(nome):
    habilidades = ["Python", "HTML", "Flask"]
    return render_template("perfil.html", nome=nome, habilidades=habilidades)
<!-- templates/perfil.html -->
<h1>Perfil de {{ nome }}</h1>
<ul>
  {% for h in habilidades %}
    <li>{{ h }}</li>
  {% endfor %}
</ul>
Exercício 1.3 — Herança de templates20 min

Crie um base.html com {% block content %}{% endblock %}, e faça home.html e sobre.html herdarem dele, para que ambas as páginas compartilhem o mesmo cabeçalho/menu.

Solução
<!-- templates/base.html -->
<html>
<head><title>{% block title %}Meu Site{% endblock %}</title></head>
<body>
  <nav><a href="/">Início</a> | <a href="/sobre">Sobre</a></nav>
  {% block content %}{% endblock %}

</html>

<!-- templates/home.html -->
{% extends "base.html" %}
{% block content %}
  <h1>Bem-vindo</h1>
{% endblock %}

2.1 Lidando com envios de formulário

Formulários enviam dados via GET (na própria URL) ou POST (no corpo da requisição). Use request.form para ler dados de POST.

from flask import request

@app.route("/contato", methods=["GET", "POST"])
def contato():
    if request.method == "POST":
        nome = request.form["nome"]
        return f"Obrigado, {nome}!"
    return render_template("contato.html")
<!-- templates/contato.html -->
<form method="POST">
  <input name="nome" placeholder="Seu nome">
  <button type="submit">Enviar</button>
</form>
Exercício 2.1 — Formulário de feedback20 min

Crie uma rota /feedback com um formulário que colete nota (1–5) e comentario. No POST, renderize um template de "obrigado" que exiba os dois valores de volta.

Solução
@app.route("/feedback", methods=["GET", "POST"])
def feedback():
    if request.method == "POST":
        nota = request.form["nota"]
        comentario = request.form["comentario"]
        return render_template("obrigado.html", nota=nota, comentario=comentario)
    return render_template("feedback.html")

2.2 Banco de dados com Flask-SQLAlchemy

Instale com pip install flask-sqlalchemy. Um model é uma classe Python que representa uma tabela do banco.

from flask_sqlalchemy import SQLAlchemy

app.config["SQLALCHEMY_DATABASE_URI"] = "sqlite:///app.db"
db = SQLAlchemy(app)

class Nota(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    texto = db.Column(db.String(200), nullable=False)

with app.app_context():
    db.create_all()
Exercício 2.2 — Salvar notas no banco25 min

Adicione uma rota /notas que: no GET, mostre um formulário e liste todas as notas existentes; no POST, salve uma nova Nota e redirecione de volta para /notas.

Solução
from flask import redirect, url_for

@app.route("/notas", methods=["GET", "POST"])
def notas():
    if request.method == "POST":
        nova_nota = Nota(texto=request.form["texto"])
        db.session.add(nova_nota)
        db.session.commit()
        return redirect(url_for("notas"))
    todas_notas = Nota.query.all()
    return render_template("notas.html", notas=todas_notas)

3.1 O model Tarefa

class Tarefa(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    titulo = db.Column(db.String(120), nullable=False)
    feita = db.Column(db.Boolean, default=False)

@app.route("/")
def index():
    tarefas = Tarefa.query.all()
    return render_template("index.html", tarefas=tarefas)

@app.route("/adicionar", methods=["POST"])
def adicionar():
    titulo = request.form["titulo"]
    if titulo.strip():
        db.session.add(Tarefa(titulo=titulo))
        db.session.commit()
    return redirect(url_for("index"))

3.2 Concluir e apagar

@app.route("/concluir/<int:tarefa_id>")
def concluir(tarefa_id):
    tarefa = Tarefa.query.get_or_404(tarefa_id)
    tarefa.feita = not tarefa.feita
    db.session.commit()
    return redirect(url_for("index"))

@app.route("/apagar/<int:tarefa_id>")
def apagar(tarefa_id):
    tarefa = Tarefa.query.get_or_404(tarefa_id)
    db.session.delete(tarefa)
    db.session.commit()
    return redirect(url_for("index"))
Em uma aplicação de produção, ações destrutivas como apagar deveriam usar POST, não GET — requisições GET podem ser disparadas por links, crawlers ou prefetch do navegador.
Exercício 3.2 — Finalizar o gerenciador30 min

Adicione links/botões "Concluir" e "Apagar" ao lado de cada tarefa em index.html, apontando para as rotas acima. Depois adicione uma mensagem flash ("Tarefa adicionada!", "Tarefa apagada.") após cada ação.

Solução
from flask import flash

app.secret_key = "dev"  # necessário para mensagens flash

@app.route("/apagar/<int:tarefa_id>")
def apagar(tarefa_id):
    tarefa = Tarefa.query.get_or_404(tarefa_id)
    db.session.delete(tarefa)
    db.session.commit()
    flash("Tarefa apagada.")
    return redirect(url_for("index"))

{% for mensagem in get_flashed_messages() %}

3.3 Fundamentos de deploy

Congele as dependências e desative o modo debug antes de publicar:

pip freeze > requirements.txt
Nunca rode com debug=True em produção — isso expõe um depurador interativo capaz de executar código arbitrário. Use uma variável de ambiente para ativá-lo, e rode a aplicação atrás de um servidor de produção como o gunicorn, em vez do servidor de desenvolvimento do Flask.
Exercício 3.3 — Checklist antes de publicar15 min

Gere o requirements.txt do seu projeto, e altere o final de app.py para que o modo debug só seja ativado quando a variável de ambiente FLASK_DEBUG estiver definida como "1".

Solução
import os

if __name__ == "__main__":
    modo_debug = os.environ.get("FLASK_DEBUG") == "1"
    app.run(debug=modo_debug)
